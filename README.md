# Culinary Compass

API-first meal-planning platform built with Symfony, PostgreSQL, React and TypeScript.

## Project Overview

Planning meals, tracking ingredients and managing shopping lists can be time-consuming, particularly for individuals and households with busy schedules. These tasks can take up valuable time that could otherwise be spent relaxing or enjoying other activities.

Culinary Compass aims to simplify this process by providing an all-in-one meal-planning platform. Users will be able to discover and save recipes, import recipes from supported websites, and plan their meals using a weekly calendar. The application will also track pantry ingredients and generate shopping lists based on what is required for planned meals and what is already available. Future features will include AI-powered recipe recommendations and meal planning based on dietary preferences.

I am rebuilding Culinary Compass using a Symfony REST API, with React and TypeScript for the web frontend and PostgreSQL for data storage. By centralising business logic in Symfony, the same backend can support multiple clients, including a future mobile application, while keeping calculations and validation consistent across platforms.

## Development Status

Culinary Compass is currently being rebuilt from scratch. The project is in its initial engineering and repository setup phase. The functionality described above represents the planned platform rather than features already implemented in this new codebase.
