# Engineering Documentation

This directory contains the technical documentation
for the Culinary Compass platform.

## Planned Documentation

- Prototype Audit: Review the existing application,
  identify issues and document what needs rebuilding.

- Requirements: Define the MVP features and acceptance
  criteria before development.

- Architecture and Decisions: Record system design,
  technology choices and the reasons behind them.

- Engineering Journal: Record development challenges,
  solutions and lessons learned throughout the project.
